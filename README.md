# 📈 Task 4 — E-Commerce Sales & Performance Dashboard

The final project focused on transforming e-commerce sales data into an **interactive Power BI dashboard** for data visualization and business reporting.

### Dashboard Features

#### 📌 KPIs

- Total Sales
- Total Quantity
- Total Orders
- Average Order Value

#### 📊 Visualizations

- Total Sales by Product
- Total Sales by Year
- Total Orders by Order Status

#### 🎛️ Interactive Filters

- Product
- Year
- Payment Method

### DAX Measures

```text
Total Sales = SUM(Order_table[TotalPrice])

Total Quantity = SUM(Order_table[Quantity])

Total Orders = DISTINCTCOUNT(Order_table[OrderID])

Average Order Value = DIVIDE([Total Sales], [Total Orders])
```
