# 📊 Data Cleaning & Preparation using Power Query

## 📖 Project Overview
This project was completed as part of the **DecodeLabs Data Analytics Internship**. The objective was to clean and prepare a raw dataset using **Microsoft Excel Power Query** to improve data quality and make it ready for analysis.

---

## 🎯 Objectives
- ✅ Handle missing values
- ✅ Remove duplicate records
- ✅ Standardize text formatting
- ✅ Correct data types
- ✅ Validate data quality

---

## 🛠️ Tools Used
- 📌 Microsoft Excel
- 📌 Power Query

---

## 🔄 Data Cleaning Steps
- 📥 Imported the dataset into Power Query.
- 🏷️ Promoted the first row as column headers.
- 🔢 Corrected data types for all columns.
- 🔄 Replaced missing (**null**) values in the **CouponCode** column with **"No Coupon"**.
- ✂️ Trimmed extra spaces from text fields.
- 🗑️ Removed duplicate records.
- ✨ Standardized text using **Capitalize Each Word**.
- ✔️ Validated unique **Order IDs** and correct **Date formats**.
- 💾 Loaded the cleaned dataset back into Excel.

---

## 📈 Project Outcome
The dataset was successfully cleaned and standardized, making it suitable for further **data analysis** and **visualization**.
