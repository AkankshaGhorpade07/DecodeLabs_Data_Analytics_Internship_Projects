# DecodeLabs_Internship_SQL_3
# 🗄️ SQL Data Analysis using PostgreSQL

## 📌 Project Overview

This project demonstrates SQL-based data analysis on an E-Commerce Sales dataset using PostgreSQL. The goal is to retrieve, analyze, and summarize business data using SQL queries.

This project was completed as part of my **Data Analytics Internship**.

---

## 🎯 Objectives

- Retrieve and filter data
- Analyze sales information
- Perform aggregations
- Generate business insights
- Practice SQL querying techniques

---

## 🛠️ Technologies Used

- PostgreSQL
- SQL
- pgAdmin 4
- Microsoft Excel (CSV)

---

## 📂 Dataset

The dataset contains **1,200 E-Commerce orders** including:

- Order ID
- Customer ID
- Product
- Quantity
- Unit Price
- Payment Method
- Order Status
- Referral Source
- Total Price

---

## 🔍 SQL Concepts Used

- SELECT
- LIMIT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()
- Subqueries

---

## 📈 Business Analysis Performed

- Displayed all orders
- Filtered orders
- Sorted sales records
- Calculated total revenue
- Calculated average order value
- Found highest & lowest orders
- Counted products sold
- Payment method analysis
- Order status analysis
- Referral source analysis
- Revenue by product
